# Automated Scoping and Product Requirements (PRD) Generator

An AI-powered web application built with **Streamlit**, **Pydantic**, and the **Google GenAI Python SDK** (`gemini-3.8-flash`) that transforms raw feature ideas, meeting notes, or unstructured text into a professional, structured Product Requirements Document.

## Features
- **Strict Schema Validation**: Uses Pydantic to ensure the model outputs reliable, structured JSON matching enterprise PRD standards.
- **Interactive UI**: Clean Streamlit interface with expandable user stories, scope boundaries, and raw JSON viewing.
- **Flexible Authentication**: Supports sidebar API key inputs, `.env` local files, and Streamlit Secrets management.
